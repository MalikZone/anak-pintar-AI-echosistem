# BAGIAN 1: Master Context Ekosistem AI (Blueprint Global & Tech Stack)

### A. Tech Stack Ekosistem

* **AI Engine & Orchestration:** Google Gemini API (didukung komputasi Google AI Plus) yang dikawal oleh **AI Orchestration Layer (Guardrail & Context Engine)** dengan kepatuhan mutlak pada filosofi **Human-in-the-Loop (HITL)** — AI bertindak murni sebagai asisten/advisor, bukan pengambil keputusan otomatis.
* **Workflow & Automation Engine:** **Temporal.io** (Durable execution, fault-tolerant background processing, scheduled cron workflows, dan distributed state management).
* **RAG & Knowledge Retrieval:** **Domain-Specific RAG** dengan PostgreSQL + **`pgvector`** terisolasi per proyek (pencarian semantik dan injeksi konteks faktual).
* **Backend Framework:** Python (FastAPI) atau Node.js (Express/NestJS) untuk kecepatan asinkronus dan kemudahan integrasi API Telegram.
* **Frontend Framework:** React.js / Next.js dengan Tailwind CSS untuk UI Dashboard yang responsif dan komponen grafik interaktif (Recharts / Chart.js).
* **Database:** PostgreSQL (Masing-masing proyek memiliki instance/database terpisah untuk isolasi penuh + ekstensi `pgvector`).
* **Containerization & Deployment:** Docker & Docker Compose per proyek untuk mendukung arsitektur *polyrepo*.
* **Messaging / Bot Integration:** Telegram Bot API (menggunakan *Webhook*).

# BAGIAN 2: Master Context Spesifik Proyek (Project-Specific Contexts)

## 2.1. Master Context Proyek `lisa` (Analisis Pasar Emas, Personal Portfolio & Proyeksi Investasi)

### A. Tech Stack Spesifik `lisa`

* **Backend:** Python (FastAPI) + `python-telegram-bot` + `temporalio` Python SDK + modul kalkulator finansial/proyeksi (NumPy / Pandas)
* **Frontend:** Next.js / React + Tailwind CSS + Recharts (visualisasi pergerakan harga emas, grafik milestone target tahunan, dan simulasi proyeksi investasi 3, 5, 10 tahun)
* **Database & RAG:** PostgreSQL (`lisa_db` dengan ekstensi `pgvector` untuk pencarian semantik berita pasar, regulasi, dan riwayat portofolio)
* **Workflow Engine:** Temporal.io (Polling berkala harga pasar emas, evaluasi otomatis milestone target, eksekusi simulasi multi-tahun)
* **Core Capabilities:**
  1. *Real-time Market & AI Recommendation Engine* (Analisis harga & rekomendasi beli/jual/simpan).
  2. *Personal Portfolio & Target Tracking* (Pencatatan aset & progres target investasi tahunan).
  3. *Historical Appreciation & Metric Analysis* (Perhitungan kenaikan persentase nilai emas YoY & ROI).
  4. *Parametric Investment Projection Engine* (Simulasi nilai investasi 3, 5, 10 tahun berbasis CAGR, skenario pasar, dan rutinitas tabungan).
  5. *Temporal Durable Workflows* (Polling harga emas multi-vendor tanpa gagal, notifikasi terjadwal, alur asinkronus).
  6. *Grounded RAG Intelligence* (Injeksi konteks pasar faktual dan portofolio terisolasi via `pgvector` ke prompt Gemini guna mencegah halusinasi).
  7. *Human-in-the-Loop Safeguard* (AI hanya memberi analisis & opsi aksi; pengguna mengeksekusi keputusan jual/beli secara mandiri).

## 2.2. Master Context Proyek `catetin` (POS SaaS Multi-Tenant & Smart Inventory)

### A. Tech Stack Spesifik `catetin`

* **Backend:** Node.js (NestJS / Express) atau Python (FastAPI) + `temporalio` SDK + *Multi-Tenant Middleware*
* **Frontend:** React / Next.js + Tailwind CSS + komponen tabel/kasir interaktif
* **Database & RAG:** PostgreSQL (`catetin_db` dengan pemisahan `tenant_id` / *Row-Level Security* + ekstensi `pgvector` untuk RAG katalog & histori transaksi)
* **Workflow Engine:** Temporal.io (Rekap penjualan harian/mingguan otomatis, alert stok menipis berkala, sinkronisasi transaksi toko)
* **Core Capabilities:**
  1. *Multi-Tenant POS & Transaction Engine* (Pencatatan kasir dan penjualan harian terisolasi).
  2. *Smart Inventory & Reorder Insights* (Deteksi stok menipis dan rekomendasi restock berbasis AI).
  3. *Temporal Scheduled Analytics & Alerts* (Workflow otomatis rekap transaksi toko dan evaluasi batas aman inventaris).
  4. *Tenant-Isolated RAG Engine* (Injeksi konteks katalog produk dan riwayat penjualan spesifik tenant via `pgvector` ke Gemini API).
  5. *Human-in-the-Loop Safeguard* (AI menyajikan rekomendasi stok/harga; kasir atau pemilik toko wajib menyetujui secara manual).
