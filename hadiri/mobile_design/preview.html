FIGMA-READY VECTOR UI

Desain Mobile App Hadirin

3 Layar Utama: Clock In, Sesi Aktif (Clock Out), dan Pengajuan Cuti.
Semua file berformat SVG Vector Murni yang dapat langsung di-drag & drop ke dalam kanvas Figma.

Cara Import ke Figma: Buka Figma (Web atau Desktop) > Buka project/file Anda > Cukup drag and drop file .svg dari folder hadiri/mobile_design/ langsung ke kanvas Figma. Figma akan otomatis membongkar seluruh layer, text, vector icon, warna gradient, dan frame menjadi elemen yang 100% dapat diedit.
